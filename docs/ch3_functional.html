汎関数：電子相関を、電子密度から見積もる

軌道近似では、電子同士が瞬間ごとに避け合う動き、電子相関を捨てていました。密度汎関数理論、DFT は、この効果を電子密度から見積もって足し戻します。その見積もりの式を交換相関汎関数と呼び、xc = "b3lyp" の xc はその略です。

1　電子密度

DFT の主役は、波動関数ではなく電子密度

水の電子密度

電子密度は、空間の各点にどれだけ電子がいるかを表します。面を描く値を変えてみましょう。

濃い所だけ薄い所まで
この面の内側にいる電子
波動関数は、電子が1個増えるごとに変数が3つずつ増えます。電子密度は、電子が何個あっても3次元の関数のままです。そのため、大きな分子でも計算できます。
2　ヤコブのはしご

汎関数は、使う情報の多さで5段のはしごに並ぶ

Perdew は汎関数を、電子密度からどれだけの情報を使うかで5段に並べ、天まで届くヤコブのはしごになぞらえました。上の段ほど多くの情報を使い、計算は重くなるかわりに、誤差が小さくなります。

右の棒は、反応エネルギーや分子間の相互作用など55種類の問題を集めた問題集、GMTKN55 での平均の誤差で、単位は kcal/mol です。短いほど正確です。

はしごを1段上るごとに、平均の誤差は小さくなります。B3LYP は4段目の混成汎関数で、計算の重さと正確さの釣り合いがよいので、長く広く使われてきました。最近は、電子同士が遠く離れたときの扱いを改めた長距離補正と、分散力を組み込んだ ωB97X-V や ωB97M-V も使われています。

汎関数ごとに得意な分子と苦手な分子があり、結果が変わる
3　分散力

B3LYP は、分子同士が弱く引き合う力を取りこぼす

メタン2分子

2つのメタンの距離を変えてみましょう。

近い遠い
分子同士の間には、電子のゆらぎから生まれる弱い引力、分散力が働きます。B3LYP は分散力を含まないので、メタン同士が引き合いません。分散力を含む ωB97X-V では、3.8 Å あたりで最も強く引き合います。B3LYP を使うときは、D3 という分散力の補正を足した B3LYP-D3 にします。
